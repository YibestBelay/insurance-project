# Insurance Pricing and Risk Analysis Project

## 📋 Project Overview
This project analyzes insurance data to develop risk-based pricing models through:
1. Exploratory Data Analysis (EDA)
2. Statistical Hypothesis Testing
3. Predictive Modeling

## 🎯 Objectives
- Understand risk factors affecting insurance claims
- Validate key business hypotheses
- Build predictive models for claim severity and premium optimization
